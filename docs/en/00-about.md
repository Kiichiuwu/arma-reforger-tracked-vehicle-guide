# About this guide

**Purpose.** This guide documents the native tracked vehicle feature of Arma Reforger (`TrackedVehicle_Base` and `VehicleTrackedSimulation`). It teaches you how to use it in future mods, from the 3D model to a driving tank.

**How it was made.** Everything here was discovered and tested while building a Leopard 2A7 mod, using only the base game. The values and errors quoted here come from that mod.

**Reference example.** The Leopard 2A7 mod serves as the example throughout the guide. Later, the mod itself will be published with this documentation, as a complete example.

**3D model used.** ["Leopard 2 A7"](https://sketchfab.com/3d-models/leopard-2-a7-b29d1cb2e65e4fa8a6e99f88e11b013b), by [king\_st0ne](https://sketchfab.com/kingstonlee96), published on Sketchfab on 25/05/2023. **Tested version.** Workbench and Arma Reforger 1.8.0.13, in October 2026. Game updates can change names, defaults and bugs.
